[ZH-CN] 屏幕保护增强 v2.0.6

新增与改进：

1. Steam UI 空值兼容：修复部分 Steam 测试版反馈的面板样式类名缺失导致插件加载报错的问题。`toScopedSelector` 校验类名类型，支持多个空白字符分隔的类名，不再对空值或非字符串调用 `.split()`。
2. 安全布局降级：`PanelSection`、`PanelSectionRow` 或整个 `staticClasses` 不可用时，跳过对应 CSS 规则，退回默认布局，避免空选择器误改根容器间距；类名正常时保留原有取值和样式。
3. 标题显示保护：标题类名增加空值保护；样式映射缺失时仍显示本地化插件名称，不因读取 `Title` 再次崩溃。
4. 回归验证与功能保留：新增 8 项回归测试，覆盖缺失对象、缺失字段、异常类型、空白字符、复合类名、CSS 作用范围和标题显示。不改变已配置的应用规则、电源设置、D-Bus 抑制、Nested 检测或通知逻辑。

兼容范围：本次针对样式字段缺失进行安全降级，并非保证所有 Steam 测试版本均无兼容问题；其他 Decky 组件的发现失败仍需对应版本适配。

升级方式：正常情况下可在插件面板检查并安装更新。若插件无法加载或旧版内置更新卡住，从本发布页下载 `ScreenSaverEnhancements-v2.0.6.zip`，打开 **Decky 设置** → **开发者** → **从 ZIP 安装插件** 安装。安装后仅重载本插件，无需重启整个 Decky Loader。

兼容安装包：同时提供 `ScreenSaverEnhancements.zip`，与带版本号的 ZIP 字节完全相同，供旧版更新器使用。

[EN] ScreenSaver Enhancements v2.0.6

Added and improved:

1. Steam UI null safety: fix plugin loading failures caused by missing panel styling classes, as reported on some Steam beta versions. `toScopedSelector` validates class values and supports whitespace-separated classes without calling `.split()` on missing or non-string values.
2. Safe layout fallback: when `PanelSection`, `PanelSectionRow` or the entire `staticClasses` map is unavailable, omit the corresponding CSS rules and fall back to the default layout. Empty selectors no longer change root-container margins; available class names and styles are preserved.
3. Title rendering protection: guard the title class map so the localized plugin name still renders without failing on a missing `Title` mapping.
4. Regression coverage and preserved behavior: add eight regression tests for missing maps and fields, invalid types, whitespace, compound classes, CSS scope and title rendering. Existing application rules, power settings, D-Bus inhibition, Nested detection and notification behavior are unchanged.

Compatibility scope: this patch safely handles missing styling fields. It does not guarantee compatibility with every Steam beta build; unrelated Decky component-discovery failures still require version-specific support.

Upgrading: normally, check for and install updates from the plugin panel. If the plugin cannot load or an older built-in updater stalls, download `ScreenSaverEnhancements-v2.0.6.zip` from this release and install through **Decky Settings** → **Developer** → **Install Plugin from ZIP**. Only this plugin needs reloading, not the entire Decky Loader.

Compatibility package: `ScreenSaverEnhancements.zip` is also provided for older updaters and is byte-identical to the versioned ZIP.
