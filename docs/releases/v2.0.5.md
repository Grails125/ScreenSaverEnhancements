[ZH-CN] 屏幕保护增强 v2.0.5

新增与改进：

1. D-Bus 启动兼容：Steam 或桌面服务占用标准接口时，仅降级对应能力，保留其他接口与手动应用监控，不抢占服务名称；占用解除后单独重试该接口。
2. 外部请求诊断：使用独立只读连接关联成功的 Inhibit/UnInhibit 调用与返回，记录 application、reason、cookie 和接口。Edge 等未加入手动列表的应用也可主动发出抑制请求；启动前或断线期间的请求可能不可见，界面会明确标注观测不完整。
3. 稳定恢复休眠：所有已知抑制来源结束后，实际恢复设置前等待 1.5 秒并重新确认；期间出现新来源则取消。恢复失败时有限重试，手动停止及时尝试恢复；通知只说明“插件已恢复原电源设置”，不再宣称系统所有抑制均已解除。
4. 诊断显示优化：默认突出监控状态、命中应用与电源接管状态；D-Bus 接口归属、外部观测、Nested 检测、技术统计及原电源设置分组折叠展示，长字段可换行，保留完整报告导出及中英乌三语支持。
5. Nested 检测降频：启动监控时先检查；无会话且进程事件订阅已确认时只等待启动事件，不做周期扫描。有会话时每 5 秒检测，查询失败每 2 秒重试；事件监听不可用时，无会话探测回退到每 10 秒一次。间隔不含查询耗时，播放/暂停识别可能延迟约 5 秒，实际恢复还需上述稳定窗口。
6. 事件与打包可靠性：兼容不同内核的进程事件订阅确认，检测订阅拒绝、确认超时及序号缺口并安全降级；监听失败后释放连接，安装包补齐独立的外部请求观测模块。已有应用规则保持不变，普通手动规则仍按进程存活判断。

升级方式：正常情况下可在插件面板检查并安装更新。若旧版内置更新卡住（包括原 v2.0.4 安装身份问题），从本发布页下载 `ScreenSaverEnhancements-v2.0.5.zip`，打开 **Decky 设置** → **开发者** → **从 ZIP 安装插件** 安装。安装后仅重载本插件，无需重启整个 Decky Loader。发布新版不会自动修复旧安装中正在运行的更新入口。

兼容安装包：同时提供 `ScreenSaverEnhancements.zip`，与带版本号的 ZIP 字节完全相同，供旧版更新器使用。

[EN] ScreenSaver Enhancements v2.0.5

Added and improved:

1. D-Bus startup compatibility: when Steam or a desktop service owns a standard interface, only that capability is degraded. Other interfaces and manual application monitoring remain active without taking over the service name. Released names are retried individually.
2. External request diagnostics: an independent read-only connection correlates successful Inhibit/UnInhibit calls and replies, recording application, reason, cookie and interface. Apps such as Edge can request inhibition without a manual rule. Requests before startup or during disconnections may be unknown; diagnostics explicitly mark observation as incomplete.
3. Stable sleep restoration: after all known inhibition sources end, wait 1.5 seconds and recheck before actually restoring settings. New sources cancel restoration; failed restoration has bounded retries, while manual shutdown attempts restoration promptly. Notifications describe only the plugin restoring its original power settings, not all system inhibitors ending.
4. Clearer diagnostics: highlight monitor status, the matched app and power override state. Group interface ownership, external observation, Nested detection, technical statistics and original power settings into expandable sections. Long values wrap; full report export and Chinese, English and Ukrainian support are retained.
5. Lower-overhead Nested detection: check on monitor startup, then wait for start events without periodic scans when no session exists and the process subscription is confirmed. Check existing sessions every 5 seconds; retry failed queries after 2 seconds. If process events are unavailable, probe for sessions every 10 seconds. Query time is additional; playback transitions can take about 5 seconds to detect before the restoration window above.
6. Event and packaging reliability: support process-subscription acknowledgements across kernels, detect rejection, confirmation timeout and sequence gaps, and fall back safely. Release failed listener connections and include the independent external-request observer module in the package. Existing rules are preserved; ordinary manual rules remain based on process lifetime.

Upgrading: normally, check for and install updates from the plugin panel. If an older built-in updater stalls, including the original v2.0.4 installer-identity issue, download `ScreenSaverEnhancements-v2.0.5.zip` from this release and install through **Decky Settings** → **Developer** → **Install Plugin from ZIP**. Only this plugin needs reloading, not the entire Decky Loader. A new release cannot repair the updater already running in an older installation.

Compatibility package: `ScreenSaverEnhancements.zip` is also provided for older updaters and is byte-identical to the versioned ZIP.
