[ZH-CN] 屏幕保护增强 v2.0.4

新增与改进：

1. 关闭内屏：新增内屏供电控制，保留黑色覆盖；两种模式共用“按任意键关闭”设置，关闭该设置时可用快捷访问键唤醒并打开面板。关闭供电后唤醒稍有延迟。
2. 嵌套桌面媒体检测：自动识别 Nested Desktop 独立会话中的 MPRIS 播放状态，播放时抑制休眠，暂停、停止或退出后解除这一路抑制；保留已有手动应用规则。
3. 乌克兰语支持：新增乌克兰语本地化，补全关闭内屏等功能的翻译，保留中文显示与英文回退。
4. 操作与唤醒响应：优化亮屏请求响应，修复触摸“立即关闭”时仅滚动按钮而未执行的问题。
5. 电源与状态恢复：加强关屏、唤醒及电源配置恢复，隔离超时请求和旧插件实例，避免快速操作或旧查询覆盖新状态。
6. 更新与设置同步：安装更新后自动重载本插件即可刷新面板，无需重启整个 Decky Loader；设置顺序保存，重新打开面板时保留待保存修改。
7. 后端可靠性：增强 D-Bus 断线恢复、请求归属校验与监听清理；播放器分别限时查询，避免单个播放器超时误解除其他播放器的抑制。
8. 界面与安装包：精简说明并统一“自动休眠时间”标签；安装包采用带版本号的文件名，更新构建依赖并核验后端模块完整性。

致谢：感谢 [@WowOne987](https://github.com/WowOne987) 通过 [PR #1](https://github.com/Grails125/ScreenSaverEnhancements/pull/1) 贡献嵌套桌面 MPRIS 播放检测与乌克兰语本地化。

[EN] ScreenSaver Enhancements v2.0.4

Added and improved:

1. Internal display power control: adds display-off mode while retaining the black overlay. Both modes share the Close on any key setting; when disabled, Quick Access wakes the display and opens the panel. Waking after display power is turned off takes a moment.
2. Nested Desktop media detection: automatically detects MPRIS playback on separate Nested Desktop session buses. Playback inhibits sleep; pause, stop, or exit releases this inhibitor. Existing manual application rules are preserved.
3. Ukrainian support: adds Ukrainian localization, including display-off controls, while preserving Chinese labels and English fallback.
4. Input and wake response: improves wake-request response and fixes touch presses that scroll the immediate display-off button without activating it.
5. Power and state recovery: strengthens display and power-profile recovery and isolates timed-out requests and retired plugin instances, preventing rapid actions or stale queries from replacing newer state.
6. Updates and settings synchronization: refreshes the panel when Decky automatically reloads this plugin after installation, without restarting the entire Decky Loader. Setting changes are saved in order and pending edits survive panel reopening.
7. Backend reliability: improves D-Bus reconnection, request ownership checks, and listener cleanup. Queries players independently with bounded timeouts so one slow player cannot discard another player's confirmed playback.
8. Interface and packaging: shortens descriptions and clarifies automatic suspend labels. Packages now include the version in their filenames; build dependencies are updated and required backend modules are verified.

Thanks to [@WowOne987](https://github.com/WowOne987) for contributing Nested Desktop MPRIS playback detection and Ukrainian localization through [PR #1](https://github.com/Grails125/ScreenSaverEnhancements/pull/1).
